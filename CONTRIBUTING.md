# Contributing to DYK Nomination Tool

Thank you for your interest in contributing! 

## How to contribute
1. Fork the repository.
2. Create a new branch for your feature or bugfix.
3. Make your changes in the `src/` directory.
4. Run tests if applicable.
5. Submit a pull request.

## Coding Style
- Please follow the existing indentation (2 spaces).
- Use single quotes for strings in JavaScript.
- Ensure your changes are compatible with the MediaWiki environment and Codex.
